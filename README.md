# Python & Machine Learning Learning Journey

Репозиторий с практикой по изучению Python и Data Science: учебные модули
и первый законченный аналитический проект.

## Структура

| Папка | Содержимое |
|---|---|
| `titanic-eda/` | Проект: EDA датасета Titanic — очистка данных, feature engineering, анализ выживаемости |
| `pandas/` | Практика по Pandas: группировки, merge, datetime, qcut |
| `numpy/` | Практика по NumPy |
| `matplotlib/` | Визуализация: графики, GridSpec |
| `python-oop/` | База Python и объектно-ориентированное программирование |

## Изученные темы

- Python (база и ООП)
- NumPy
- Pandas
- Matplotlib
